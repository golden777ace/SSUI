# SSUI

**SSUser Interface** — современная, сверхлёгкая и предельно быстрая GUI-библиотека для Windows, написанная с нуля на Rust с публичным API на Python.

> ⚠️ **Статус:** активная разработка (alpha). Нативное 2D-ядро на Rust работает, поверх него — декларативный Python-API через PyO3. Каталог виджетов закрыт: доступны прозрачность, размытие фона, изображения, диалоги, уведомления, рисование и терминал.

---

## Что это

SSUI — попытка сделать то, чем должен был бы стать Tkinter сегодня: **простую в использовании** библиотеку с **огромным арсеналом настроек**, построенную на современном GPU-рендеринге вместо устаревшей софтверной отрисовки.

Два принципа, вокруг которых строится всё остальное:

1. **Простота использования.** Декларативный API, стилизация через CSS, разумные значения по умолчанию, четыре готовые темы «из коробки».
2. **Широкий спектр настроек.** Любой элемент — форма со свойствами (позиция, цвета, границы, тени, градиенты, прозрачность) и правилами взаимодействия. Любой цвет можно переопределить поверх темы.

## Что уже работает

### Ядро на Rust
- ⚡ **GPU-рендеринг** через Direct3D 11 + Direct2D + DirectWrite (flip-model swap chain, high-DPI).
- 🧱 **Дерево элементов** на аренном `Vec`; кэш геометрии (пересчёт только при изменениях).
- 📐 **Раскладка:** линейный поток + constraint — flex-веса (`grow`), выравнивание по осям (`align`), абсолютные якоря (`pin`), узлы, прозрачные для мыши (`ghost`), глубина `z` (`dep`/`bindz`) и подъём панели кликом (`front`).
- 🧩 **Три размещения:** `pl` (абсолют), `gr` (сетка со span), `pk` (упаковка по сторонам с fill/expand).
- 🎨 **Четыре темы:** white, light, dark, black; смена темы из кода (`thm`), семантические токены.
- ⌨️ **Ввод:** мышь (hover/press/drag, колесо, курсоры), клавиатура, фокус, Tab/Shift+Tab, Enter/Space, **IME**, приём файлов из проводника.
- 📝 **Редактор текста:** каретка, выделение мышью и Shift-стрелками (в однострочном и многострочном), Home/End, Delete, Ctrl+A/C/V/X/Z/Y, буфер обмена с переносами строк, undo/redo, прокрутка.
- 🖼️ **Изображения:** PNG/JPEG через WIC, кэш битмапов, режимы вписывания (contain/cover/fill/center), иконки в кнопках и метках.

### Каталог виджетов

**Контейнеры:** Frame, Box, GroupBox, Scroll Area, Splitter, Tabs, Accordion, Stack, Dock, Drop Area, Canvas.

**Отображение:** Label, Image, Icon, Separator, Progress Bar, Spinner, Gauge, Chart, Meter, Status Bar, Badge.

**Кнопки и действия:** Button, Toggle Button, Drop-down, Link, Split Button.

**Ввод:** Text Entry, Text Area, CheckBox, Radio, Switch, Slider, Range Slider, Dial/Knob, SpinBox, ComboBox, Terminal.

**Данные:** ListBox, Table (с настраиваемыми разделителями строк и столбцов), Tree View, Property Grid.

**Навигация:** Menu, Menu Bar, Scroll Bar, Breadcrumbs, Pagination.

**Выбор значений:** Calendar, Time Picker, Color Picker, Rating.

**Окна и оповещения:** Dialog, Message Box, Alert, Tooltip, Toast, Notification, Snackbar.

### Оформление
- 🎨 **CSS-каскад:** селекторы по типу/классу/`*`, группы через запятую, комбинаторы (` `, `>`), специфичность, наследование (`color`, `wrap`), псевдосостояния `:hover`/`:focus`, фон, цвет, отступы, радиус, перенос, тени, градиенты.
- ♻️ **Hot-reload стилей:** `css_hot(path)` следит за файлом и перезагружает его на лету.
- 📜 **Виртуализация:** списки, таблицы, дерево и таблица свойств рисуют только видимые строки.
- 🌈 **Градиенты** с направлением (вертикаль, горизонталь, две диагонали).
- 🌑 **Тени/elevation** для панелей и кнопок.
- 🫥 **Прозрачность:** альфа-канал в цветах (`#RRGGBBAA`) и настоящее прозрачное окно через DirectComposition.
- 🪟 **Размытие фона за окном** (DWM) с гашением на время перемещения ради плавности.

### Python-API (PyO3)
- 🐍 Декларативная композиция через `with`-контексты и краткие имена.
- ✳️ **Сигналы** и точечная реактивность (перерисовка привязок при изменении).
- 🔁 **Реактивные данные:** пункты списков (`bindl`) и строки таблиц (`bindt`) из сигналов, без пересборки дерева.
- 🎞️ **Анимации** (кривые, длительности, тикер 60 Гц).
- 🧰 **Диалоги, меню, подсказки, уведомления, инспектор раскладки (F12)**.
- 🎚️ Живое управление окном из кода: тема, тон фона, режим размытия.

## Пример на Python

```python
import ssui

def main():
    vol = ssui.sgnl(0.0)

    win = ssui.W("Привет, SSUI", 640, 480, thm="drk", glass=True, blur=True)
    fx = win.fx()
    thm = win.thm()

    with win.bx(rad=16.0, pd=20.0, gp=12.0):
        win.lb(bind=lambda: f"Громкость: {int(vol() * 100)}%", h=28.0)
        win.gg(bind=lambda: vol(), lb="VOL", h=130.0)
        win.sl(0.0, ch=lambda v: vol.st(v), h=36.0)
        win.bt("В 100%", h=44.0, tip="Плавно до максимума",
               toast="Готово ✓", clk=lambda: fx(vol, 1.0, dur=0.5))
        win.bt("Светлая тема", h=44.0, clk=lambda: thm("lit"))

    win.go()

if __name__ == "__main__":
    main()
```
