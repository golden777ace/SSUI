# SSUI

**Sergievskiy Sergey User Interface** — современная, сверхлёгкая и предельно быстрая GUI-библиотека для Windows, написанная с нуля.

> ⚠️ **Статус:** ранняя разработка (pre-alpha). Публичного API ещё нет, всё в этом файле — проектное видение. Ничего не готово к использованию.

---

## Что это

SSUI — попытка сделать то, чем должен был бы стать Tkinter сегодня: **простую в использовании** библиотеку с **огромным арсеналом настроек**, построенную на современном GPU-рендеринге вместо устаревшей софтверной отрисовки.

Два принципа, вокруг которых строится всё остальное:

1. **Простота использования.** Декларативный API на Python, стилизация через CSS, разумные значения по умолчанию, четыре готовые темы «из коробки».
2. **Широкий спектр настроек.** Любой элемент — это форма в трёх координатах со свойствами (позиция, цвета, прозрачность, границы) и правилами взаимодействия с другими элементами. Кастомизировать можно всё.

## Ключевые особенности (цели проекта)

- ⚡ **GPU-ускорение** через Direct3D / Direct2D / DirectWrite — аппаратная отрисовка и качественный текст без внешних зависимостей.
- 🦀 **Нативное ядро на Rust** — производительность на уровне C, память-безопасность без сборщика мусора, минимальное потребление памяти.
- 🐍 **Python-фронтенд** поверх нативного ядра (модель Tkinter: быстрое ядро + удобный скриптовый слой).
- 🎨 **Стилизация через CSS** — знакомый синтаксис снижает порог входа.
- 🌗 **Четыре темы сразу:** white, light, dark, black.
- 🧩 **Всё из примитивов.** Фрейм, текст, кнопка, ползунок — и их комбинации образуют все остальные виджеты.
- 🔮 **Задел на 3D-интерфейсы** (высота, ширина, глубина) — заложен архитектурно, реализуется на поздних фазах.
- ✳️ **Fine-grained реактивность** на сигналах — перерисовывается только то, что изменилось.

## Технологический стек

| Слой | Технология |
|------|-----------|
| Ядро движка | Rust |
| Окно и ввод | Win32 API (через `windows` crate) |
| Рендеринг | Direct3D 11/12 + Direct2D + DirectWrite |
| Публичный API | Python 3.11+ (биндинги через PyO3) |
| Стили | Подмножество CSS → полный CSS |
| Раскладка | Гибрид: линейная + constraint-солвер |
| Реактивность | Сигналы (fine-grained) |

## Как это будет выглядеть (черновой API — всё может измениться)

```python
import ssui
from ssui import App, Window, Frame, Text, Button, signal

def main():
    count = signal(0)

    app = App()
    with Window(title="Hello SSUI", size=(400, 300), theme="dark"):
        with Frame(css_class="container"):
            # Текст реактивен: перерисуется сам при изменении count
            Text(lambda: f"Нажатий: {count()}")
            Button("Нажми меня", on_click=lambda: count.set(count() + 1))

    app.run()

if __name__ == "__main__":
    main()
```

```css
/* styles.css */
.container {
    display: flex;
    flex-direction: column;
    gap: 12px;
    padding: 16px;
}
```

## Структура проекта

```
SSUI/
├─ core/            # Нативное ядро на Rust
│  ├─ platform/     # Win32: окно, ввод, DPI
│  ├─ render/       # D3D / Direct2D / DirectWrite, Canvas
│  ├─ layout/       # линейная раскладка + constraint-солвер
│  ├─ events/       # hit-testing, диспетчеризация, фокус
│  ├─ style/        # токены, темы, движок CSS
│  └─ memory/       # аренные аллокаторы
├─ bindings/        # PyO3-биндинги Rust ↔ Python
├─ ssui/            # Python-пакет: декларативный API, сигналы, виджеты
├─ examples/
├─ tests/
├─ docs/
├─ ROADMAP.md
├─ README.md
└─ LICENSE
```
