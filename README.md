# SSUI

**SSUser Interface** — современная, сверхлёгкая и предельно быстрая GUI-библиотека для Windows, написанная с нуля на Rust с публичным API на Python.

> ⚠️ **Статус:** активная разработка (alpha). Нативное 2D-ядро на Rust работает, поверх него — декларативный Python-API через PyO3. Открывается окно, на GPU рисуется интерактивный интерфейс, доступны прозрачность, размытие фона, изображения и богатый набор виджетов.

---

## Что это

SSUI — попытка сделать то, чем должен был бы стать Tkinter сегодня: **простую в использовании** библиотеку с **огромным арсеналом настроек**, построенную на современном GPU-рендеринге вместо устаревшей софтверной отрисовки.

Два принципа, вокруг которых строится всё остальное:

1. **Простота использования.** Декларативный API, стилизация через CSS, разумные значения по умолчанию, четыре готовые темы «из коробки».
2. **Широкий спектр настроек.** Любой элемент — форма со свойствами (позиция, цвета, границы, тени, градиенты, прозрачность) и правилами взаимодействия. Любой цвет можно переопределить поверх темы.

## Что уже работает

### Ядро на Rust
- ⚡ **GPU-рендеринг** через Direct3D 11 + Direct2D + DirectWrite (flip-model swap chain, high-DPI).
- 🧱 **Дерево элементов** на аренном `Vec`; кэш геометрии (пересчёт только при изменениях).
- 📐 **Раскладка:** линейная + constraint — flex-веса (`grow`), выравнивание по осям (`align`), абсолютные якоря (`pin`).
- 🎨 **Четыре темы:** white, light, dark, black (переключение пробелом), семантические токены.
- 🧩 **Виджеты:** Frame, Label, Button, Slider, ProgressBar, Checkbox, TextBox, TextArea, Dropdown, Tabs, Table, Image, Switch, Radio, Toggle, Separator, SpinBox, ListBox, GroupBox, Link, Accordion, Scroll Area, Stack, Splitter, Spinner, Gauge, Tooltip, Toast.
- ⌨️ **Ввод:** мышь (hover/press/drag, курсоры), клавиатура, фокус, навигация **Tab/Shift+Tab**, активация Enter/Space, колесо прокрутки, **IME**.
- 📝 **Редактор текста:** каретка, выделение мышью и Shift-стрелками, Home/End, Delete, Ctrl+A/C/V/X/Z/Y, буфер обмена, undo/redo, прокрутка; многострочный режим (TextArea).
- 🖼️ **Изображения:** загрузка PNG/JPEG через WIC, кэш битмапов, четыре режима вписывания (contain/cover/fill/center), иконки в кнопках и метках.

### Оформление
- 🎨 **CSS-подмножество:** селекторы по типу/классу/`*`, псевдосостояния `:hover`/`:focus`, свойства фона, цвета, отступов, радиуса, переноса.
- 🌈 **Градиенты** с направлением (вертикаль, горизонталь, две диагонали).
- 🌑 **Тени/elevation** для панелей и кнопок.
- 🫥 **Прозрачность:** альфа-канал в цветах (`#RRGGBBAA`) и настоящее прозрачное окно через DirectComposition.
- 🪟 **Размытие фона за окном** (glass/blur) с гашением на время перемещения ради плавности.

### Python-API (PyO3)
- 🐍 Декларативная композиция через `with`-контексты и краткие имена.
- ✳️ **Сигналы** и точечная реактивность (перерисовка привязок при изменении).
- 🎞️ **Анимации** (кривые, длительности, тикер 60 Гц).
- 🧰 **Диалоги, контекстное меню, подсказки, уведомления, инспектор раскладки (F12)**.
- 🎚️ Живое управление настройками окна (тон фона, режим размытия) из кода.

## Пример на Python

```python
import ssui

def main():
    vol = ssui.sgnl(0.0)

    win = ssui.W("Привет, SSUI", 640, 480, thm="drk", glass=True, blur=True)
    fx = win.fx()

    with win.bx(rad=16.0, pd=20.0, gp=12.0):
        win.lb(bind=lambda: f"Громкость: {int(vol() * 100)}%", h=28.0)
        win.gg(bind=lambda: vol(), lb="VOL", h=130.0)
        win.sl(0.0, ch=lambda v: vol.st(v), h=36.0)
        win.bt("В 100%", h=44.0, tip="Плавно до максимума",
               toast="Готово ✓", clk=lambda: fx(vol, 1.0, dur=0.5))

    win.go()

if __name__ == "__main__":
    main()
```
