# SSUI

**SSUser Interface** — современная, сверхлёгкая и предельно быстрая GUI-библиотека для Windows, написанная с нуля.

> ⚠️ **Статус:** активная разработка (alpha). Нативное 2D-ядро на Rust уже работает: открывается окно, на GPU рисуется интерактивный интерфейс. Публичного Python-API пока нет — он следующий по плану.

---

## Что это

SSUI — попытка сделать то, чем должен был бы стать Tkinter сегодня: **простую в использовании** библиотеку с **огромным арсеналом настроек**, построенную на современном GPU-рендеринге вместо устаревшей софтверной отрисовки.

Два принципа, вокруг которых строится всё остальное:

1. **Простота использования.** Декларативный API, стилизация, разумные значения по умолчанию, четыре готовые темы «из коробки».
2. **Широкий спектр настроек.** Любой элемент — форма со свойствами (позиция, цвета, границы) и правилами взаимодействия. Цвет любого элемента можно переопределить поверх темы.

## Что уже работает (нативное ядро на Rust)

- ⚡ **GPU-рендеринг** через Direct3D 11 + Direct2D + DirectWrite (flip-model swap chain, high-DPI).
- 🧱 **Дерево элементов** на аренном `Vec` + линейная раскладка (направление, отступы, gap, фиксированные и растяжимые размеры).
- 🎨 **Четыре темы:** white, light, dark, black (переключение пробелом), семантические токены.
- 🧩 **Примитивы:** `Frame`, `Text`, `Button`, `Slider`.
- 🔧 **Композиты:** `Checkbox`, `ProgressBar`, `TextBox` (полноценный однострочный редактор).
- ⌨️ **Ввод:** мышь (hover/press/drag, курсоры), клавиатура, фокус, навигация **Tab/Shift+Tab**, активация Enter/Space.
- 📝 **Редактор текста:** каретка, выделение мышью и Shift-стрелками, Home/End, Delete, Ctrl+A/C/V/X/Z/Y, буфер обмена, undo/redo.
- 🎯 **Переопределение стиля** на уровне элемента (`set_style`) и **колбэки** (`on_click`, `on_change`) — задаются кодом приложения.

## В планах

- 🐍 **Python-фронтенд** через PyO3 (модель Tkinter: быстрое ядро + удобный скриптовый слой).
- 🧮 **Constraint-раскладка** в дополнение к линейной; кэш геометрии.
- 🎨 **Стилизация через CSS** (подмножество → полный).
- ✳️ **Fine-grained реактивность** на сигналах.
- 🎞️ **Анимации**; позже — задел на **3D-интерфейсы**.

## Демонстрация

Рабочий пример собран на Rust — окно с панелью, счётчиком, кнопками, чекбоксом, полем ввода, ползунком и прогресс-баром:

```powershell
cargo run --example clear_screen
```

## Как это будет выглядеть в Python (черновой API — всё может измениться)

```python
import ssui
from ssui import App, Window, Frame, Text, Button, signal

def main():
    count = signal(0)

    app = App()
    with Window(title="Hello SSUI", size=(400, 300), theme="dark"):
        with Frame(css_class="container"):
            Text(lambda: f"Нажатий: {count()}")
            Button("Нажми меня", on_click=lambda: count.set(count() + 1))

    app.run()

if __name__ == "__main__":
    main()
```
