# Фаза 0 — Фундамент

Цель фазы: окно открывается, инициализируется устройство Direct3D 11, экран
очищается цветом на GPU, работает цикл сообщений, ресайз и high-DPI, окно
чисто закрывается.

## Что реализовано

- **`platform::dpi`** — включение Per-Monitor-v2 DPI awareness.
- **`platform::window`** — регистрация класса окна, создание окна, оконная
  процедура, блокирующий цикл сообщений; обработка `WM_PAINT`, `WM_SIZE`,
  `WM_ERASEBKGND`, `WM_DPICHANGED`, `WM_DESTROY`, `WM_NCDESTROY`.
- **`render::device`** — устройство D3D11, flip-model swap chain, render target
  view, очистка экрана и `Present`; корректный ресайз буферов.
- **`examples/clear_screen.rs`** — запускаемая демонстрация.

## Предпосылки

- Windows 10/11 (x64).
- Rust с тулчейном MSVC: `rustup default stable-x86_64-pc-windows-msvc`.
- Установленные Build Tools for Visual Studio (компоновщик MSVC).

## Сборка и запуск

Из корня репозитория:

```powershell
cargo run --example clear_screen
```

Ожидаемо: окно 1280×720 с ровным тёмным фоном.

## Критерии готовности (Definition of Done)

- [ ] Окно открывается и заливается фоновым цветом.
- [ ] Ресайз работает плавно и без мерцания.
- [ ] На мониторе с масштабом > 100% картинка чёткая, не замыленная.
- [ ] Перенос окна между мониторами с разным DPI корректно меняет размер.
- [ ] Окно закрывается чисто, процесс завершается (`WM_QUIT`).

## Замечания по версии `windows`-crate

Код написан под `windows = "0.58"`. Эта библиотека периодически меняет
сигнатуры между версиями. Если сборка ругается, наиболее вероятные точки
расхождения:

- **Возвращаемые типы**: некоторые функции возвращают `Result<T>` в одних
  версиях и «сырой» тип — в других (`CreateWindowExW`, `SetWindowPos`,
  `ResizeBuffers`).
- **`HMODULE` → `HINSTANCE`**: используется `instance.into()`. Если конверсия
  недоступна, замените на `HINSTANCE(instance.0)`.
- **`ClearRenderTargetView`**: цвет передаётся как `*const f32`
  (`clear_color.as_ptr()`). В некоторых версиях параметр — `&[f32; 4]`; тогда
  передавайте `&clear_color`.
- **`DXGI_SWAP_CHAIN_DESC1.Flags`**: здесь `u32` (`0`). Если тип поля —
  `DXGI_SWAP_CHAIN_FLAG`, замените на `DXGI_SWAP_CHAIN_FLAG(0)`.
- **Передача `None`** в параметры-хендлы (`padapter`, `hWndParent`, `hMenu`)
  опирается на трейт `Param`; в редких версиях может потребоваться явный
  `HWND::default()` и т. п.

При появлении ошибок компиляции пришлите текст — поправим точечно.
